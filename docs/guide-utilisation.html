01
Prise en main

Démarrage

Lancer l’application en local. La première page affichée est toujours l’écran de connexion.

Dans le dossier du projet :

npm run dev

Ouvrez http://localhost:3000 dans le navigateur.

Après un build de production (npm run build) :

npm run start

04

Gestes communs

Tous les écrans métier fonctionnent de la même façon. Seuls les champs, statuts et libellés changent.

Consulter

Tableau par défaut, ou vue fiches (icône grille). Cliquez sur la référence ou « Ouvrir la fiche » pour le détail. Les pastilles de statut : vert = OK, jaune = à surveiller, magenta = bloquant, cyan = en cours.

Rechercher et filtrer

Tapez dans la barre de recherche, filtrez par statut, parcourez les pages. « Effacer les filtres » si la liste est vide.

Créer / Modifier / Supprimer

Bouton principal en haut à droite pour créer (champs * obligatoires). Menu ⋯ → Modifier. Menu ⋯ → Supprimer (confirmation, administrateur uniquement).

Exporter, imprimer, restaurer

Exporter génère un CSV des lignes filtrées. Imprimer depuis la fiche. L’icône de rotation restaure le jeu mock de cet écran uniquement.

01
Fondations

Configuration & Paramétrage

Poser les fondations avant de vendre ou de produire : catalogue produits et matières, tarifs, machines, modèles de documents et règles d’entreprise. À utiliser à la mise en service, puis à chaque nouveau produit, matière ou équipement.

Catalogue matières

À quoi ça sert

Gérer les papiers, encres, plaques et autres matières : libellé, prix d’achat, prix de vente, stock, seuil d’alerte et unité.

Comment l’utiliser
  1. Configuration → onglet Catalogue matières.
  2. Nouvelle matière : type, libellé, prix d’achat et de vente, quantité d’alerte, unité. Le stock reste à 0 et n’est pas modifiable ici : il augmente à la validation d’un approvisionnement.
  3. À côté de Type et Unité : + pour ajouter, crayon pour renommer, corbeille pour supprimer.
  4. Le statut (Disponible / Stock bas / Rupture) se calcule d’après le stock et la quantité d’alerte.

Catalogue produits et prestations

À quoi ça sert

Décrire flyers, cartes, catalogues, affiches, packaging ou une prestation (conception, mise en page) avec une désignation complète.

Comment l’utiliser
  1. Configuration → onglet Catalogue. Le switch Produit / Prestation sépare les deux listes.
  2. Nouveau produit ou Nouvelle prestation : pour un produit, côtés imprimés, papier, options. Produit comme prestation peuvent recevoir des matières premières (libellé, quantité, unité), facultatives. Pour une prestation, les champs papier sont masqués.
  3. Statut Actif = vendable ; Brouillon = en préparation ; Archivé = retiré.

Astuce. Un produit actif sert de référence aux devis et au calculateur de prix.

Grilles tarifaires et règles de prix

À quoi ça sert

Pour chaque produit ou prestation du catalogue, indiquer le montant selon la quantité (paliers dégressifs).

Comment l’utiliser
  1. Onglet Grilles tarifaires : le switch Produit / Prestation filtre la liste.
  2. Cliquez une ligne. Saisissez « Pour 100, le montant est … ». Ajoutez d’autres paliers avec +.
  3. Enregistrez. On ne crée pas de nouvelle règle ici.

Paramétrage des machines et postes

À quoi ça sert

Capacités, cadences et coûts horaires pour les calculs de production et de rentabilité.

Comment l’utiliser
  1. Nouveau poste : atelier, cadence, coût horaire, capacité quotidienne.
  2. À côté d’Atelier : + pour ajouter, crayon pour renommer, corbeille pour supprimer.
  3. Maintenance ou Hors service si indisponible.

Modèles de documents

À quoi ça sert

Concevoir visuellement devis, bons de commande, factures et BL sur une feuille A4.

Comment l’utiliser
  1. Nouveau modèle : saisissez le libellé, puis Concevoir.
  2. Sur l’A4 : insérez logo, titre, texte, tableau ; déplacez les blocs. Centrez le texte via les boutons d’alignement. Un logo importé n’affiche que le motif, sans fond.
  3. Valider génère le HTML. Un clic dans la liste affiche le design.

Taxes

À quoi ça sert

Créer, modifier ou supprimer les taxes (libellé, code, pourcentage). Les activer ou les désactiver. Seules les taxes actives s’appliquent aux devis et factures.

Comment l’utiliser
  1. Configuration → onglet Taxes.
  2. Nouvelle taxe : libellé, pourcentage, code et précision facultatifs. Activez avec l’interrupteur.
  3. Dans le tableau, le même interrupteur active ou désactive une taxe sans ouvrir la fiche.

Paramètres généraux

À quoi ça sert

Identité de l’entreprise, logo, site web et coordonnées. Les montants s’affichent sans symbole de devise.

Comment l’utiliser
  1. Renseignez la fiche entreprise puis Enregistrer.
  2. Les taxes se gèrent dans l’onglet Taxes.
02

Utilisateurs & Sécurité

Qui a le droit de faire quoi, ce qui a été modifié, et comment les données sont sauvegardées.

Gestion des rôles et permissions

À quoi ça sert

Créer les rôles (libellé + droits CRUD par module), puis les comptes utilisateurs auxquels les affecter.

Comment l’utiliser
  1. Onglet Rôles : libellé, puis cochez Créer / Consulter / Modifier / Supprimer pour chaque module de la barre latérale.
  2. Onglet Utilisateurs : nom, téléphone, adresse, mot de passe (ou génération à 4 chiffres). L’e-mail est facultatif. Affectez un rôle déjà créé.

Seul un administrateur peut supprimer un compte via le menu ⋯.

Journal des actions (audit trail)

À quoi ça sert

Tracer les modifications importantes : qui, quoi, quel module, quelle date.

Comment l’utiliser
  1. Recherchez un auteur, un module ou un dossier.
  2. Ouvrez la ligne pour consulter le détail. Aucune création, modification ni suppression.

Sauvegarde et sécurité des données

À quoi ça sert

Générer une sauvegarde des données locales et en garder l’historique.

Comment l’utiliser
  1. Cliquez sur Sauvegarder : une ligne Réussie apparaît dans le tableau.
  2. Consultez le volume et l’heure d’exécution.
03

Gestion des Clients (CRM)

Centraliser la relation client, de la fiche 360° aux commandes et aux contacts.

Fiche client détaillée

À quoi ça sert

Fiche 360° : particulier ou entreprise, avec remise éventuelle et note interne.

Comment l’utiliser
  1. Nouveau client : choisissez Particulier ou Entreprise. Les champs du formulaire changent.
  2. Particulier : nom, téléphone, e-mail, adresse. Entreprise : identité complète (raison sociale, NINEA, contact…).
  3. Renseignez si besoin une remise éventuelle et une note interne.

Historique des commandes

À quoi ça sert

Consultation uniquement : voir les devis, commandes, factures et acomptes d’un particulier ou d’une entreprise. On n’ajoute rien ici.

Comment l’utiliser
  1. La liste affiche les fiches clients (particuliers et entreprises). Filtrez par statut ou recherchez un nom.
  2. Cliquez sur le client ou « Consulter les commandes » : les commandes précédentes apparaissent (référence, travail, date, total).
  3. Le bouton Filtres affiche le type (devis, commande, facture…) et les dates du / au.
  4. Ouvrez une ligne pour le détail, puis revenez aux commandes.

Segmentation client

À quoi ça sert

Classer les clients pour le commercial et le marketing. Le type (secteur) se choisit à la main. L’importance et le comportement se calculent tout seuls d’après les commandes enregistrées.

Comment l’utiliser
  1. Par type de client : créez, renommez ou supprimez un secteur, puis Affecter des clients (recherche à autocomplétion, un ou plusieurs, entreprises ou particuliers).
  2. Par importance et Par comportement : consultation seule. Filtrez par Entreprise / Particulier ou par groupe.
Par type de client

Affectation manuelle à un secteur d’activité. Un client n’a qu’un secteur à la fois. Secteurs proposés (modifiables) :

  • Entreprises
  • Particuliers
  • Écoles
  • Restaurants
  • Hôtels
  • Associations
  • Agences de communication
  • Administrations
Par importance (automatique)

Un seul groupe par client, du plus fort au plus faible :

  • Clients VIP : total des commandes ≥ 3 000 000.
  • Gros clients : total des commandes ≥ 1 000 000.
  • Clients réguliers : au moins 5 commandes, sans atteindre gros ou VIP.
  • Petits clients : moins de 5 commandes et total inférieur à 1 000 000.
Par comportement (automatique)

Un seul groupe par client, d’après la date des commandes :

  • Commandent souvent : au moins 2 commandes sur les 90 derniers jours.
  • Commandent rarement : au moins une commande sur les 6 derniers mois, sans fréquence élevée.
  • Rien commandé depuis 6 mois : aucune commande dans les 183 derniers jours (y compris jamais commandé).

Gestion des contacts multiples

À quoi ça sert

Une entreprise n’est pas une seule personne. Ex. ABC Communication = Jean (direction), Sarah (marketing), Paul (comptabilité), Michel (livraison). Le logiciel sait qui contacter, et pour quelle raison.

Comment l’utiliser
  1. La liste affiche les entreprises déjà créées dans Fiches clients (pas les particuliers).
  2. Ouvrir les contacts, puis Ajouter un contact : nom, rôle, e-mail, téléphone.
  3. Le bloc « Qui contacter » indique qui reçoit le BAT, la facture ou l’avis de livraison.
Rôles
  • Direction — décision, relance.
  • Responsable marketing — valider un visuel.
  • Responsable comptabilité — envoyer la facture.
  • Responsable livraison — commander prête / BL.
  • Validation BAT — bon à tirer avant impression.
Exemple

Affiche terminée → Sarah, marketing. Facture → Paul, comptabilité. Colis prêt → Michel, livraison.

À retenir

On n’ajoute pas une nouvelle entreprise ici. On rattache plusieurs personnes à une société déjà en fiche.

04

Devis & Commandes

Chaîne commerciale : du chiffrage à la commande ferme.

Calculateur de prix automatique

À quoi ça sert

Chiffrer un travail à partir du client et du catalogue, puis l’éditer sur une feuille A4 aux couleurs NanoPrint.

Comment l’utiliser
  1. Nouveau chiffrage : recherchez le client. S’il existe, ses coordonnées et sa remise s’affichent (à appliquer ou non). Sinon, créez un particulier ou une entreprise, puis reprenez.
  2. Étape 2 : saisissez le produit. Le calculateur lit la grille tarifaire (paliers de quantité), refuse une quantité trop basse, applique le palier correspondant, puis ajoute papier et options. La remise client s’active avec l’interrupteur.
  3. Quand le chiffrage est complet, Imprimer / PDF ouvre directement l’A4 (Saira, barre de marque, taxes actives). Imprimez ou enregistrez en PDF, sans choisir de modèle.

Génération de devis multi-options

À quoi ça sert

Même assistant que le calculateur, pour proposer plusieurs variantes (quantités, papiers, finitions) dans un seul devis.

Comment l’utiliser
  1. Nouveau devis : client (création possible), puis produits du catalogue avec grilles et remise.
  2. Un même produit peut être repris plusieurs fois. Dupliquez une option pour n’en changer que le papier, la quantité ou les finitions.
  3. Imprimer / PDF ouvre directement l’A4 NanoPrint. Imprimez ou enregistrez en PDF, sans choisir de modèle.

Conversion devis vers commande

À quoi ça sert

Transformer un chiffrage du calculateur en commande, sans ressaisie.

Comment l’utiliser
  1. Saisissez la référence du devis (CHF-…). Le détail complet s’affiche.
  2. Convertir en commande : le devis passe à Converti, la commande naît En attente dans le suivi.
  3. Choisissez ensuite le modèle de document à imprimer (ou PDF), comme dans le calculateur.

Suivi des statuts de commande

À quoi ça sert

État temps réel des commandes nées de la conversion : en attente, en production, en finition, expédiée.

Comment l’utiliser
  1. Consultez une commande : même détail que le devis (client, lignes, montant) plus l’échéance.
  2. Changez uniquement le statut. Pas de création ni de modification des autres champs.
  3. Supprimez si besoin (administrateur). Imprimer / PDF reprend les modèles publiés.

Gestion des avenants

À quoi ça sert

Modifier une commande non terminée (produits, impression, papier, options, quantité, échéance) sans perdre l’ancienne version. Le prix se recalcule comme au calculateur. Le statut ne se change pas ici.

Comment l’utiliser
  1. La liste montre les commandes en cours (pas encore expédiées). Cliquez-en une, ou saisissez sa référence (CMD-…).
  2. Consultez le détail, puis Modifier la commande : changez produit, côtés, papier, options, quantité ou échéance, et le motif.
  3. Enregistrer crée l’avenant et met à jour la commande. Le statut se change dans le suivi des commandes.

Prépresse & Fichiers

Recevoir et stocker les fichiers clients rattachés aux commandes converties.

Réception et stockage des fichiers clients

À quoi ça sert

Déposer un ou plusieurs PDF, AI ou InDesign sur une commande, remplacer une version corrigée, ou supprimer un fichier.

Comment l’utiliser
  1. Choisissez une commande (liste ou référence CMD-…). Le détail complet s’affiche.
  2. Déposer des fichiers : un ou plusieurs à la fois. Un fichier du même nom incrémente la version.
  3. Remplacer dépose la version corrigée. Supprimer retire le fichier du dossier.
06

Planification (Ordonnancement)

Voir ce qui est prévu sur chaque machine, et quand.

Planning visuel des machines

À quoi ça sert

Voir d’un coup d’œil quelle machine est occupée, quand elle est libre, et quelle commande passe ensuite.

Comment l’utiliser
  1. La grille montre la semaine : une ligne par machine, un jour par colonne (lundi à samedi).
  2. Chaque case affiche la commande (CMD-…) et l’horaire (08h → 11h). Libre = créneau disponible.
  3. Cliquez une case libre pour placer une commande, ou une commande pour la déplacer / la retirer.
07

Achats & Fournisseurs

Acheter papier, encres et services au bon prix, puis réceptionner.

Fiches fournisseurs

À quoi ça sert

Fiche simple : nom complet, téléphone, adresse, e-mail. Historique des achats passés auprès du fournisseur.

Comment l’utiliser
  1. Nouveau fournisseur : nom, téléphone, adresse, e-mail.
  2. Consulter, modifier ou supprimer depuis le menu. Historique des achats : approvisionnements validés et réceptions.

Approvisionnement

À quoi ça sert

Commander des matières auprès d’un fournisseur. Le prix d’achat vient du catalogue et n’est pas modifiable. La validation incrémente le stock et édite le bon de livraison.

Comment l’utiliser
  1. À gauche, recherchez le fournisseur. À droite, recherchez la matière : le stock s’affiche dans la liste, puis la ligne s’ajoute avec PA, PV et quantité.
  2. Saisissez la quantité : le total de ligne et le total général se recalculent. Les prix restent figés.
  3. Valider : le bon de livraison s’affiche, le stock matières augmente.

Historique d’approvisionnement

À quoi ça sert

Retrouver les approvisionnements par fournisseur : total, date et nombre d’appros. Le détail affiche les matières. Suppression possible dans les 48 heures.

Comment l’utiliser
  1. La liste montre le fournisseur, le total, la dernière date et le nombre d’appros.
  2. Détails : les approvisionnements effectués, avec les lignes et le bon de livraison.
  3. Supprimer uniquement un approvisionnement de moins de 48 h : le stock est alors recalé.
08

Stocks & Consommables

Ne jamais lancer un job sans matière disponible.

Suivi stock

À quoi ça sert

Voir le stock des produits finis et des matières premières. Retirer une quantité (cassé, perte, calage…).

Comment l’utiliser
  1. Basculez Produits finis / Matière première.
  2. Retirer : quantité (sans dépasser le stock) et motif.

Seuils d’alerte de réapprovisionnement

À quoi ça sert

Être notifié au stock minimum pour commander à temps.

Comment l’utiliser
  1. Configurer un seuil : minimum, actuel, fournisseur.
  2. Commande lancée une fois le BA créé.

Inventaire et régularisation

À quoi ça sert

Compter le physique, constater l’écart, ajuster le système.

Comment l’utiliser
  1. Saisissez le stock système et le stock physique : l’écart se calcule tout seul (physique − système).
  2. Régularisé après correction.

Machines & Maintenance

Fiche technique de chaque machine

À quoi ça sert

Modèle, capacité, heures d’utilisation, documentation.

Comment l’utiliser
  1. Ajouter une machine à l’arrivée d’un équipement.
  2. Mettez à jour En production / En panne / Maintenance.

Maintenance préventive planifiée

À quoi ça sert

Entretenir selon les heures, les feuilles ou le calendrier, avant la panne.

Comment l’utiliser
  1. Planifier : machine, déclencheur, échéance.
  2. Terminée après l’intervention.

Signalement de pannes

À quoi ça sert

Déclaration rapide par l’opérateur, suivi jusqu’à résolution.

Comment l’utiliser
  1. Signaler : machine, opérateur, date, résolution.
  2. Informez le planning : créneaux à déplacer.

Suivi du taux d’utilisation des machines

À quoi ça sert

Temps productif / temps disponible pour repérer les goulots.

Comment l’utiliser
  1. Saisir : heures disponibles, productives, taux %.
  2. Goulot = file d’attente ; Sous-utilisé = rééquilibrer.

Comment l’utiliser

13

Facturation & Comptabilité

Facturer et encaisser depuis les commandes converties, sans ressaisie.

Facturation automatique

À quoi ça sert

Générer une facture A4 de solde ou d’acompte depuis une commande, sans la modifier ni la supprimer ensuite.

Comment l’utiliser
  1. Choisissez la commande, puis Solde (reste entier) ou Acompte.
  2. Pour un acompte, saisissez un montant supérieur à zéro et inférieur au total restant. Générer ouvre l’aperçu A4.

Gestion des acomptes

À quoi ça sert

Encaisser un acompte sur une commande : le payé augmente, le reste diminue. Un reçu A4 peut être imprimé.

Comment l’utiliser
  1. Choisissez la commande, indiquez le montant, puis Payer.
  2. Imprimez le reçu de paiement. Pas de modification ni de suppression manuelle des lignes.

Pointage du temps de travail

À quoi ça sert

Comment l’utiliser

À quoi ça sert

N’affecter à une machine que les opérateurs habilités.

Comment l’utiliser

  2. Filtrez À renouveler / Expirée avant d’affecter.

Analyse

Reporting & Tableaux de bord

Décider sur des chiffres, en bout de chaîne.

Tableau de bord de l’activité

À quoi ça sert

Parcours type d’un dossier

Ordre d’utilisation aligné sur le cahier des charges : configuration → exploitation → reporting.

  1. 01Configuration — produit, tarif, poste machine.
  2. 02Clients — fiche et contacts (dont validateur BAT).
  3. 03Devis — calculateur → conversion en commande (En attente) → suivi des statuts.
  4. 04Prépresse — dépôt des fichiers clients sur la commande.
  5. 05Stocks / Achats — vérifier le stock ou commander.
  6. 06Planification — créneau machine sur la grille semaine.
  7. 07Livraison — BL, tournée ou retrait, suivi colis.
  8. 08Facturation — acompte puis facture A4 depuis la commande.
  9. 09Communication — notifications aux étapes clés.
  10. 10Reporting — clôture de période.

Limites de la version mock

Ce que la démo ne fait pas encore, pour éviter les malentendus en formation.

  • Aucune base de données, aucun e-mail ou SMS réellement envoyé.
  • Les fichiers ne sont pas stockés sur un serveur.
  • Les données vivent dans ce navigateur. Un autre PC ou une navigation privée revient au jeu de démo.
  • La suppression n’est autorisée qu’en profil Administrateur.
  • L’icône de restauration ne remet à zéro que l’écran courant.

Ensuite. Quand un vrai backend sera branché, les mêmes écrans et les mêmes gestes resteront valables ; seul le stockage changera.
