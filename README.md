# NanoPrint

Plateforme d’administration pour imprimerie (Next.js, données mock).

## Démarrage

```bash
npm run dev
```

Ouvrez [http://localhost:3000](http://localhost:3000), puis connectez-vous.

Compte de démonstration : `awa.diop@nanoprint.demo` / `demo2026`.
